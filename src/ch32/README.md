# ch32 - Rope Swings and Traversal Gadgets

Chapter 32 of *Building Two Classic Platform Games*.

Open `ch32.slnx` for this chapter alone, or `../PlatformBook.slnx` for all
forty-six, foldered by the book's four parts.

    Both      dotnet build ch32.slnx -c Release
    Android   dotnet build Android/ch32.Android.csproj -c Release -t:Run
    iOS       dotnet build iOS/ch32.iOS.csproj -c Release \
                  -p:RuntimeIdentifier=ios-arm64

Orientation: Portrait (locked)
Shared code in `Game/`, art and audio linked from `../../assets/hunch`.
