# ch34 - Projectiles and Patrolling Knights

Chapter 34 of *Building Two Classic Platform Games*.

Open `ch34.slnx` for this chapter alone, or `../PlatformBook.slnx` for all
forty-six, foldered by the book's four parts.

    Both      dotnet build ch34.slnx -c Release
    Android   dotnet build Android/ch34.Android.csproj -c Release -t:Run
    iOS       dotnet build iOS/ch34.iOS.csproj -c Release \
                  -p:RuntimeIdentifier=ios-arm64

Orientation: Portrait (locked)
Shared code in `Game/`, art and audio linked from `../../assets/hunch`.
