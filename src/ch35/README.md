# ch35 - The Screen Goal and the Bell

Chapter 35 of *Building Two Classic Platform Games*.

Open `ch35.slnx` for this chapter alone, or `../PlatformBook.slnx` for all
forty-six, foldered by the book's four parts.

    Both      dotnet build ch35.slnx -c Release
    Android   dotnet build Android/ch35.Android.csproj -c Release -t:Run
    iOS       dotnet build iOS/ch35.iOS.csproj -c Release \
                  -p:RuntimeIdentifier=ios-arm64

Orientation: Portrait (locked)
Shared code in `Game/`, art and audio linked from `../../assets/hunch`.
