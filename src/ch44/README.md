# ch44 - Settings, Saves and Shared Score Data

Chapter 44 of *Building Two Classic Platform Games*.

Open `ch44.slnx` for this chapter alone, or `../PlatformBook.slnx` for all
forty-six, foldered by the book's four parts.

    Both      dotnet build ch44.slnx -c Release
    Android   dotnet build Android/ch44.Android.csproj -c Release -t:Run
    iOS       dotnet build iOS/ch44.iOS.csproj -c Release \
                  -p:RuntimeIdentifier=ios-arm64

Orientation: Portrait (locked)
Shared code in `Game/`, art and audio linked from `../../assets/both`.
