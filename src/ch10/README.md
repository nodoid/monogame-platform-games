# ch10 - Sourcing and Making Sound Effects

Chapter 10 of *Building Two Classic Platform Games*.

Open `ch10.slnx` for this chapter alone, or `../PlatformBook.slnx` for all
forty-six, foldered by the book's four parts.

    Both      dotnet build ch10.slnx -c Release
    Android   dotnet build Android/ch10.Android.csproj -c Release -t:Run
    iOS       dotnet build iOS/ch10.iOS.csproj -c Release \
                  -p:RuntimeIdentifier=ios-arm64

Orientation: Portrait (locked)
