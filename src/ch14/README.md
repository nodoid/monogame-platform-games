# ch14 - The Static Playfield

Chapter 14 of *Building Two Classic Platform Games*.

Open `ch14.slnx` for this chapter alone, or `../PlatformBook.slnx` for all
forty-six, foldered by the book's four parts.

    Both      dotnet build ch14.slnx -c Release
    Android   dotnet build Android/ch14.Android.csproj -c Release -t:Run
    iOS       dotnet build iOS/ch14.iOS.csproj -c Release \
                  -p:RuntimeIdentifier=ios-arm64

Orientation: Portrait (locked)
Shared code in `Game/`, art and audio linked from `../../assets/climber`.
