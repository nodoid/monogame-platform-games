# ch19 - The Hammer and Power-Ups

Chapter 19 of *Building Two Classic Platform Games*.

Open `ch19.slnx` for this chapter alone, or `../PlatformBook.slnx` for all
forty-six, foldered by the book's four parts.

    Both      dotnet build ch19.slnx -c Release
    Android   dotnet build Android/ch19.Android.csproj -c Release -t:Run
    iOS       dotnet build iOS/ch19.iOS.csproj -c Release \
                  -p:RuntimeIdentifier=ios-arm64

Orientation: Portrait (locked)
